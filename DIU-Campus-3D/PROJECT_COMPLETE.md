## 🚀 Quick Start

### Step 1: Navigate to Project
```bash
cd "d:\level 4 term 3\Computer-Grapics-Lab-main\Computer-Grapics-Lab-main\DIU-Campus-3D"
```

### Step 2: Compile
```bash
mingw32-make
```

### Step 3: Run
```bash
./DIU_Campus.exe
```

### Step 4: Explore!
- Press **W/A/S/D** to move
- Press **Arrow Keys** to look around
- Press **N** for night mode
- Press **P** to pause animations
- Press **R** to reset camera
- Press **ESC** to exit
